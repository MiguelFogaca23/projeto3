# Biblioteca

Sistema de biblioteca com Node.js, Express, PostgreSQL e frontend em HTML, CSS e JavaScript.

## Modulos

- Autores
- Editoras
- Livros, com upload de capa
- Fichas catalograficas, em relacao 1:1 com livros

## Execucao

1. Configure `backend/.env` com as credenciais do PostgreSQL.
2. Execute `documentacao/biblioteca.sql` no banco configurado.
3. Inicie a API com `npm run dev` ou `npm start`.
4. Abra `index.html` pelo Live Server.
